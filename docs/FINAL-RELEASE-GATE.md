# Final release gate

Complete all applicable checks before calling the project production-ready.

- [ ] Production content is verified and licensed.
- [ ] Demo/placeholder content has been removed.
- [ ] No secrets are present in public repository files.
- [ ] Authentication is protected by a backend.
- [ ] Premium entitlements are verified server-side.
- [ ] Payment webhooks are verified and idempotent.
- [ ] Ad rewards are verified server-side.
- [ ] Production video access is protected.
- [ ] Privacy Policy and Terms are final and published.
- [ ] PWA install/offline/update behavior passes QA.
- [ ] Mobile layout passes QA.
- [ ] Critical security issues are resolved.
- [ ] Backups and monitoring are configured.

Until all required checks pass, keep production payment, ad, authentication, and protected-video services disabled.
