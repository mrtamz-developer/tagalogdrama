# App store preparation

## Before submitting a mobile build

- [ ] App name, icon, screenshots, and descriptions are final.
- [ ] Privacy Policy URL is published.
- [ ] Terms of Service URL is published where required.
- [ ] Support/contact information is current.
- [ ] Content rights are verified for every published title.
- [ ] Age/content rating is accurate.
- [ ] Account deletion/data deletion requirements are implemented where applicable.
- [ ] Payment and subscription disclosures match the actual implementation.
- [ ] No demo content is presented as official/licensed content.
- [ ] Production backend endpoints use HTTPS.
- [ ] Release build contains no development secrets or debug credentials.

## Android/iOS packaging

Native packaging and store signing should be completed only after the web/PWA release gate passes. Keep signing keys and store credentials outside the public repository.
