# Demo data policy

The current catalog contains placeholder/demo metadata for development and UI testing.

Before production launch:

1. Replace demo titles, artwork, descriptions, episode metadata, and media references.
2. Verify rights for each production asset in `docs/CONTENT-RIGHTS-REGISTER.md`.
3. Remove any placeholder media that could be mistaken for licensed content.
4. Test the final catalog through the release QA matrix.

Demo data must never be represented to users as licensed or officially distributed content.
