# TagalogDrama launch checklist

## Product
- [ ] Replace all placeholder titles, artwork, synopses, and episode metadata with verified content.
- [ ] Confirm rights/licenses for every video, image, music track, and logo.
- [ ] Connect production video hosting with signed/private playback URLs where appropriate.

## Accounts and payments
- [ ] Add secure authentication and account recovery.
- [ ] Connect the selected payment provider and verify webhooks server-side.
- [ ] Never expose payment secret keys in frontend code.
- [ ] Verify subscription entitlement on the server.

## Advertising
- [ ] Connect an approved rewarded-ad SDK.
- [ ] Verify ad rewards server-side before unlocking premium episodes.
- [ ] Add required consent/privacy disclosures.

## Privacy and legal
- [ ] Publish final Privacy Policy and Terms.
- [ ] Add required Filipino/Philippine consumer disclosures where applicable.
- [ ] Configure consent before production analytics.

## Release
- [ ] Test mobile browsers and Android WebView/PWA behavior.
- [ ] Test offline fallback and service-worker updates.
- [ ] Test favorites, progress, catalog routing, and broken-network behavior.
- [ ] Run a production security review before accepting real users or payments.
