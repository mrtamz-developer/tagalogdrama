# TagalogDrama project status

## Implemented

- Static streaming-style homepage and navigation
- Centralized series and episode metadata
- Subscription plan configuration (payment deferred)
- Rewarded-ad configuration (provider deferred)
- Feature flags
- English/Filipino UI translation foundation
- Privacy-first settings
- Analytics event schema without an analytics provider
- PWA offline fallback and versioned cache
- Service-worker update checks
- Release, security, deployment, and content-rights checklists

## Intentionally not enabled yet

- PayMongo/payment processing
- Real user authentication
- Production video hosting/playback protection
- Production rewarded-ad SDK
- Production analytics

These require backend/service credentials and security validation before activation.

## Current repository rule

Do not treat placeholder catalog entries or media URLs as licensed production content. Replace them only after rights have been verified.
