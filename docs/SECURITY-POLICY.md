# Security policy

## Scope

This repository is currently a frontend/PWA project. Production authentication, payments, ad rewards, and protected video services are not enabled.

## Reporting a vulnerability

Do not publish secrets, credentials, private URLs, or exploit details in public issues. Report security concerns privately to the repository owner through an available private GitHub security-reporting channel.

## Secret handling

Never commit passwords, API keys, payment secret keys, signing credentials, database credentials, or private tokens.

## Production rule

A feature is not production-ready merely because a frontend control exists. Privileged operations must be enforced by a trusted backend before activation.
