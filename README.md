# TagalogDrama

TagalogDrama is a short-drama streaming app for Filipino/Tagalog audiences.

## Planned Features

- Short drama series and episodes
- Daily subscription
- Weekly subscription
- Monthly subscription
- Watch selected episodes free with rewarded ads
- User accounts
- Watch history
- Favorites
- Continue watching
- Mobile-first video player
- Admin/content management

## Important

Only publish video content that you own or are properly licensed to distribute.
