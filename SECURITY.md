# Security Policy

## Reporting a vulnerability

Please do not publish security vulnerabilities, credentials, tokens, private video URLs, or other sensitive information in public issues.

Report suspected security problems privately to the repository owner so they can be reviewed and fixed.

## Secrets

Never commit `.env` files, payment secret keys, database service-role keys, signing secrets, or private media credentials. Use the deployment provider's encrypted environment variables.

## Content

Only publish video, images, music, logos, and other media that TagalogDrama owns or is licensed to distribute.
